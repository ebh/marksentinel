# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Instead, use GitHub's private
reporting: go to the [Security tab](https://github.com/ebh/marksentinel/security) and
click **Report a vulnerability**. This opens a private advisory visible only to you and
the maintainer, separate from public issues.

Include what you'd include in a bug report: affected version, reproduction steps, and
impact.

## Supported versions

marksentinel does not yet have a stable release; the latest commit on `main` is the
supported version.
